# Memory — kebiasaan rumah

Bukan hasil training. File ini aturan tetap.

Yang dipelajari dari chat (contoh: bawang → Belanja Dapur) ada di database, bukan di file ini.

- Suami: Ardy.
- Wallet default: Kas Rumah Tangga.
- Istri / doe / dompet / jajan dia → Dompet Istri.
- Tabungan Rumah dan Dana Darurat jangan dipakai jajan harian kecuali disebut eksplisit.
- Bawang, cabai, sayur, lauk pasar → Belanja Dapur. Kalau ragu, tanya dulu.
- Gorengan, warung, kopi, aqua botol → Food & Drink.
- Galon / isi ulang air → Daily Needs.
